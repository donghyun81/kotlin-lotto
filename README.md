# kotlin-lotto

- 돈
    - [x] 구입하는 금액이 돈보다 높으면 예외 처리
    - [x] 돈이 음수일 경우 예외 처리

- 구매자
    - [x] 돈으로 로또들을 구매
    - [x] 구매 가능한 개수 반환

- 로또
    - [x] 로또 번호 포함 여부 확인

- 로또 번호들
    - [x] 로또 번호가 6개가 아닐 경우 예외 처리
    - [x] 로또 번호 포함 여부 반환
    - [x] 겹치는 로또 번호들을 반환

- 로또 순위들
    - [x] 로또 상품의 총합을 반환하는 기능

- 로또 순위
    - [x] 로또들의 순위를 반환하는 기능

- 로또 번호
    - [x] 1~45의 숫자가 아닐 경우 예외 처리

- 당첨 번호
    - [x] 보너스 번호가 당첨 번호와 중복 될 경우 예외처리
    - [x] 다른 로또와 겹치는 개수 반환
    - [x] 보너스 번호 포함 여부 반환

- 당첨 순위
    - [x] 당첨 개수에 따른 등수 반한 기능 추가
        - 맞는 개수 6개 1등 2000000000원
        - 맞는 개수 5개 보너스 포함 2등 30000000원
        - 맞는 개수 5개 3등 1500000원
        - 맞는 개수 4개 4등 50000원
        - 맞는 개수 3개 5등 5000원
        - 그외 0원

- 로또 생성 기계
    - [x] 랜덤 숫자 로또 생성 기능
    - [x] 수동 숫자 로또 생성 기능

- 로또 서비스
    - [x] 로또들의 순위를 계산하는 기능
    - [x] 로또들의 총 수익을 계산하는 기능

- 로또 단일 상태 흐름 관리
    -  [x] 당첨 번호 초기화 기능
    -  [x] 당첨 번호 초기화 여부 반환
    -  [x] 로또 티켓 반환
    - [x] 당첨 번호 반환
    - [x] 자동 구매 개수 반환
    - [x] 로또 구매
